# CS 210 Lab 3 — Login/Signup UI

A styled login and sign-up interface with a login-history page.

## Pages
- `login.html` — login form
- `signup.html` — sign-up form
- `loginHistory.html` — login history view

## Tech stack
- HTML, CSS (`style.css`)

## What I learned
- Designing consistent auth screens (login + sign-up + history)
- Form layout and styling with CSS
- Reusing styles across multiple pages

## How to view
Open `login.html` in any browser.
